# 📱 PST Store - المستورد (El-Mostawred)
### متجر إلكتروني متكامل لبيع الإلكترونيات (لابتوبات استيراد وجديد، موبايلات، إكسسوارات)

---

## 🌟 نظرة عامة على التطبيق
تم تصميم وتطوير التطبيق ليعمل بكفاءة وسلاسة تامة على هواتف **أندرويد (APK)** و **آيفون (iOS)** وشاشات الكمبيوتر، بتصميم **Mobile-First** يحاكي أحدث تطبيقات المتاجر العالمية مع دعم كامل للغة العربية (RTL).

---

## 🛠️ أقسام ومميزات التطبيق
1. **لابتوبات استيراد فرز أول A+ وجديد بالكرتونة:**
   * علامات تجارية رائدة: Dell Latitude, Lenovo ThinkPad, HP ZBook Workstation, Asus TUF Gaming, MacBook.
   * فلترة بالمواصفات: المعالج، الرامات، وحدة التخزين SSD، كارت الشاشة، وحالة الجهاز.
2. **هواتف ذكية:**
   * هواتف آيفون (استيراد دبي فرز أول فحص 100% وبطاريات 85%+).
   * هواتف أندرويد (سامسونج، شاومي، بكسل) كسر زيرو وجديد بالضمان.
3. **شواحن وإكسسوارات وهاردوير:**
   * شواحن أصلية Type-C و GaN ولابتوب وآيفون.
   * رامات DDR4/DDR5، هاردات NVMe SSD، شنط لابتوب ضد الصدمات، كابلات معتمدة.
4. **سلة مشتريات حية وطلب سريع عبر واتساب:**
   * سلة مشتريات ديناميكية لحساب الإجمالي ومصاريف الشحن.
   * نموذج طلب يرسل رسالة منسقة تلقائياً لكافة المنتجات ومواصفاتها وعنوان العميل عبر واتساب المتجر.
5. **لوحة تحكم مصغرة (إدارة المتجر):**
   * إمكانية إضافة منتجات جديدة أو تعديل الأسعار والمواصفات وحفظها في التخزين المحلي للمتصفح.
6. **دعم PWA و Capacitor:**
   * مهيأ للتحويل المباشر إلى ملف **Android APK** وملف **iOS IPA**.

---

## 🚀 كيفية تشغيل وتجربة التطبيق الآن على الكمبيوتر
1. اضغط نقراً مزدوجاً على الملف:
   `تشغيل_تطبيق_المستورد.bat`
2. سيفتح التطبيق فوراً في نافذة هاتف ذكي مستقلة (App Mode) بدون أشرطة المتصفح لتجربته كما يظهر على الموبايل تماماً.

---

## 📲 كيفية استخراج ملف أندرويد (APK) و iOS

### الطريقة الأولى: استخراج APK و iOS عبر Capacitor (Native Build)
المشروع مجهز بملفات `capacitor.config.json` و `package.json`:
1. افتح موجه الأوامر في مجلد `PST-ElMostawred`.
2. قم بتثبيت التبعيات (إذا كان لديك Node.js):
   ```bash
   npm install
   ```
3. لإضافة بيئة أندرويد وبناء الـ APK:
   ```bash
   npx cap add android
   npx cap open android
   ```
   (سيفتح Android Studio، ومن قائمة `Build` اختر `Build Bundle(s) / APK(s)` ثم `Build APK`).

4. لإضافة بيئة iOS:
   ```bash
   npx cap add ios
   npx cap open ios
   ```
   (يفتح في Xcode لنظام Mac لعمل Archive واستخراج الـ IPA).

---

### الطريقة الثانية (الأسهل والأسرع): تحويل فوري لـ APK عبر PWABuilder
1. ارفع مجلد المشروع على استضافة سريعة مجانية (مثل Netlify، Vercel، أو GitHub Pages).
2. افتح موقع: [PWABuilder.com](https://www.pwabuilder.com)
3. أدخل رابط موقعك، وسيقوم الموقع بفحص ملف `manifest.json` و `sw.js` الذي أنشأناه لك، وسيعطيك زر لتحميل ملف **Android APK** جاهز فوراً للتثبيت، وملف **iOS Package** أيضاً!

---

### الطريقة الثالثة: التثبيت الفوري على أي هاتف (بدون متجر)
1. افتح ملف `index.html` أو رابط موقعك من متصفح الهاتف (Chrome في أندرويد، أو Safari في آيفون).
2. في أندرويد: اضغط على القائمة (ثلاث نقاط) واختر **"تثبيت التطبيق" (Install App)** أو **"الإضافة للشاشة الرئيسية"**.
3. في آيفون: اضغط على زر المشاركة (Share) ثم اختر **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)**.
4. سيظهر تطبيق **PST المستورد** بأيقونته وشاشته الكاملة بدون متصفح ويعمل حتى بدون إنترنت!
